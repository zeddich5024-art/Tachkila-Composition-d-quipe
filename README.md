# Tachkila-Composition-d-quipe
## Présentation du projet

TACHKILA est une application web qui permet d'organiser l'effectif d'une équipe de football. Le projet consiste à afficher les joueurs et à les positionner sur un terrain selon la formation tactique 4-4-2.

## Objectifs

- Créer une interface simple et facile à utiliser.
- Organiser les joueurs selon leurs postes.
- Visualiser la composition de l'équipe sur un terrain.
- Pratiquer HTML, CSS et JavaScript à travers un projet concret.

## Technologies utilisées

- **HTML5** :structure de la page.
- **CSS3** : mise en forme et design.
- **JavaScript** : interactions et gestion des joueurs.
- **CSS Grid** : organisation des positions sur le terrain.

## État d'avancement

Le projet est actuellement en cours de développement.

Les premières étapes réalisées sont :
- Mise en place de l'interface principale.
- Création du header et de la liste des joueurs.
- Intégration du terrain de football en formation 4-4-2.
- Création du formulaire d'ajout d'un joueur.
- Organisation visuelle des différents postes.
